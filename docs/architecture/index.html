How StormSense works

Every morning it answers one question: given the weather coming this week, which stores will run short, which have extra, and what should move where.

  1. Weather
  2. Forecast
  3. Shortage and surplus
  4. Transfers
  5. A planner decides

Running in the Databricks workspace

  • 15 Delta tables in workspace.stormsense, built by serverless notebooks
  • Forecaster registered in Unity Catalog as champion: weighted error 0.39 against 0.67 for “same as last week” and 0.57 for the 28-day average
  • Three workflows, including the daily run at 6:00 AM Eastern, using live weather from the National Weather Service
  • The Ask space, created from code over eight tables: it answered all 10 sample questions correctly on the real data and cannot change anything
  • The app, run locally, reads and writes the workspace: approvals update the transfers table and leave an audit trail

As of October 8, 2026. Data is generated sample data until real feeds are connected.

Built, not yet switched on

  • Real sales, stock and weather feeds in place of the sample tables

Decisions behind the design

The browser never sees Databricks

Only the API talks to the workspace, as the app’s own service principal. Planners see stores, products and moves, never tables or queries.

Fixed screens, free-form Ask

Today, Transfers and forecasts use constant, parameterized queries. Ask is a separate read-only space for open questions.

Approvals can’t double-apply

The update only touches rows still pending and stamps its request id, so a repeat or a second person is told “already handled”. Every attempt is audited.

The forecaster must earn its place

It is promoted to champion only if it beats two simple baselines on the last four weeks, which are never used for training.

Safe to re-run

Forecast, gaps and weather writes replace one day; recommendations merge into pending rows only. Decided rows are never overwritten.

Created from code

Two bundles and a script create the jobs, tables, forecaster, Ask space and app. Nothing is assembled by hand in the workspace.
